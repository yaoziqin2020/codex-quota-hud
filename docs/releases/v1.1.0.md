# Codex Quota HUD v1.1.0

## English

`v1.1.0` makes the current-user Inno Setup installer the primary Windows
installation path. It supports English and Simplified Chinese, requires no
administrator elevation, and upgrades `v1.0.0` in place while preserving HUD
settings and Developer Preview window state by default.

The installer selects current-user startup and the Developer Preview desktop
shortcut by default. The normal HUD starts in the background at sign-in and
remains available from the Start menu; it does not create a normal desktop
shortcut. ZIP users can also run `CodexQuotaHud.App.exe --preview` explicitly.
Normal uninstall preserves settings; the user must explicitly opt in to purge
the exact settings directory.

The Setup executable is unsigned, so Windows SmartScreen can show an
unknown-publisher warning. Verify the downloaded SHA-256 against
`SHA256SUMS.txt` before running it. The ZIP and bundled PowerShell installer
remain a fallback only. GitHub Packages is not used.

Release assets:

- `CodexQuotaHud-Setup-v1.1.0.exe`
- `CodexQuotaHud-v1.1.0-win-x64.zip`
- `SHA256SUMS.txt`

Verification passed Core `55/55`, App/UI `332/332`, total `387/387`; Release
build `0` warnings and `0` errors; and all four isolated installer smoke
scenarios. Real Windows acceptance passed overwrite install, settings
preservation, startup and shortcut verification, default settings-preserving
uninstall, and explicit purge uninstall.

## 简体中文

`v1.1.0` 将当前用户 Inno Setup 安装器作为 Windows 的主要安装方式。安装器支持英文和
简体中文，不需要管理员权限；可原地从 `v1.0.0` 升级，默认保留 HUD 设置和开发预览窗口状态。

安装器默认勾选当前用户开机启动和“开发预览”桌面快捷方式。正式 HUD 登录时在后台启动，
也可从开始菜单打开，但不创建普通桌面快捷方式。ZIP 用户也可明确运行
`CodexQuotaHud.App.exe --preview`。普通卸载保留设置；只有用户明确选择清除时，
才会删除准确的设置目录。

Setup 未签名，Windows SmartScreen 可能显示未知发布者提示。运行前应使用 `SHA256SUMS.txt`
核对 SHA-256。ZIP 和其中的 PowerShell 安装脚本仅作为后备路径；不使用 GitHub Packages。

发布资产包括 Setup、ZIP 后备包和 `SHA256SUMS.txt`。验证结果为 Core `55/55`、
App/UI `332/332`、总计 `387/387`，Release 构建 `0` 警告、`0` 错误，四个隔离 smoke 场景均通过。
真实 Windows 覆盖安装、设置保留、启动项、快捷方式、普通卸载及明确清除卸载均已验收。
