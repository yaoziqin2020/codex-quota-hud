# Codex Quota HUD v1.1.1

## 简体中文

`v1.1.1` 修正了 `v1.1.0` 的安装器发行边界，面向普通用户安装。

- Setup 默认勾选当前用户开机启动和“创建桌面快捷方式”。
- 桌面快捷方式与开始菜单入口均启动真实 HUD，不带 `--preview`。
- Setup 不创建、不显示任何开发预览入口。
- 从 `v1.1.0` 升级时会移除由该版本创建的“开发预览”桌面快捷方式。
- 开发预览仍可由源码或 ZIP 用户明确运行
  `CodexQuotaHud.App.exe --preview`；维护者本机可另行创建快捷方式。
- 默认保留 HUD 设置和开发预览窗口状态；卸载时只有明确选择才清除设置。

Setup 仍为当前用户安装，无需管理员权限，并提供简体中文和英文。安装包未签名，
Windows SmartScreen 可能显示未知发布者，请使用 `SHA256SUMS.txt` 核对下载文件。

发布资产：

- `CodexQuotaHud-Setup-v1.1.1.exe`
- `CodexQuotaHud-v1.1.1-win-x64.zip`
- `SHA256SUMS.txt`

## English

`v1.1.1` corrects the installer release boundary from `v1.1.0` and is the
recommended build for ordinary users.

- Setup selects current-user startup and creation of the desktop shortcut by
  default.
- Both desktop and Start-menu shortcuts launch the real HUD without
  `--preview`.
- Setup neither creates nor exposes a Developer Preview entry point.
- Upgrading from `v1.1.0` removes the Developer Preview desktop shortcut
  created by that release.
- Developer Preview remains explicitly available to source and ZIP users with
  `CodexQuotaHud.App.exe --preview`; a maintainer may create a separate local
  shortcut.
- HUD settings and Developer Preview window state are preserved by default;
  uninstall removes settings only when the user explicitly chooses that
  option.

Setup remains a current-user, no-administrator install with Simplified Chinese
and English. It is unsigned, so Windows SmartScreen may show an unknown
publisher warning; verify downloads against `SHA256SUMS.txt`.

Release assets:

- `CodexQuotaHud-Setup-v1.1.1.exe`
- `CodexQuotaHud-v1.1.1-win-x64.zip`
- `SHA256SUMS.txt`
