# Codex Quota HUD 1.0.0

首个公开版本。解压 Windows 安装包后，在包内目录运行：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\install.ps1
```

## 主要功能

- 同时显示 Codex 5 小时与每周剩余额度
- 五套独立动态皮肤与对应藏边进度条
- 单击详情、双击刷新、右键完整控制菜单
- 多显示器、不同 DPI、顶部/底部/左右外侧边缘藏边
- 托盘图标直接显示剩余百分比
- 每 60 秒后台刷新，Codex 退出后浮窗随之退出
- 当前用户开机启动、安全安装与卸载脚本
- 只读取本机 `codex app-server` 数据，不保存账号或令牌

## Download

Download `CodexQuotaHud-v1.0.0-win-x64.zip`, extract it, then run the
installation command above. The package is self-contained for Windows x64
and does not require a separate .NET Runtime installation.

This is an independent open-source project and is not an official OpenAI
product.
