## 简体中文

`v1.3.0` 补齐皮肤作者的文字构图与预览验收工具：

- 新增“文字整体上下偏移”（`-32..32 DIP`）和“数字/时间间距”
  （`-16..32 DIP`）两个持久化参数。旧 v1.2.x 包缺字段时按 `0/0` 读取，
  原视觉不变；新输出仍使用 schema `1`，但最低 HUD 自动声明为 `1.3.0`。
- 新增默认关闭、不可点击拦截且只存在于设计器预览中的构图参考线。
- 新增不会写入草稿、撤销历史、应用或导出数据的单项动画预演。
- 明确显示 `free-decoration-ring` 模板预览的 Dual 外圈为 5 小时、内圈为每周，
  并同步说明 5h、Week、None；五款内置皮肤保留既有圈层几何。
- Windows 原生导出选择器会从 `Documents\Codex Quota HUD Skins` 开始，
  文件名栏只放叶子 `.cqskin` 名称。
- 应用与导出结果显示准确的皮肤名、版本、ID、最终目录和真实激活状态；
  “已安装但未确认切换”不会写成实时切换成功。

Setup 的普通用户契约不变：开机启动与正式版桌面快捷方式默认勾选且允许取消，
快捷方式不带 `--preview`；皮肤设计器可见但默认不勾选；ZIP 只含正式 HUD
后备包；Setup 会移除开发预览入口。维护者机器上的开发预览快捷方式仅作为本地
状态，在产品安装验证后另行恢复为准确的 `--preview`，不是 Setup 行为。

`v1.3.0` completes the Skin Designer's text-composition and preview acceptance
tooling:

- Persisted Text vertical offset (`-32..32 DIP`) and Number/time line-gap
  increment (`-16..32 DIP`) controls. Missing v1.2.x properties default to
  `0/0`; new output remains schema `1` and requires HUD `1.3.0`.

  history, Apply, or Export data.
- Explicit Dual outer = 5h / inner = Week guidance for the
  `free-decoration-ring` template preview, plus 5h, Week, and None
  explanations. The five built-in skins retain their established geometry.
- A native Windows export picker rooted in
  `Documents\Codex Quota HUD Skins` with only a leaf filename.
- Exact Apply/Export feedback for skin name, version, ID, final directory, and
  truthful activation disposition.

shortcut default selected and may be deselected; the shortcut has no
