# Codex Quota HUD v1.2.2

## 简体中文

`v1.2.2` 是皮肤包元数据修正版，不改变 `.cqskin` 格式或安装器结构。

- 导入皮肤时将 `作者（未验证）` 改为 `作者`。当前版本没有作者身份验证系统，
  因此不再对所有作者显示容易误解的“未验证”状态。
- 内置 `free-decoration-ring` 模板现在自动声明真实最低兼容版本 HUD `1.2.0`，
  不再由界面或作者手工填写错误的 `1.1.1`。
- 旧草稿、已安装皮肤和导入编辑的旧皮肤包会在设计器内自动采用有效最低版本；
  下次保存、应用或导出时会写入正确值。
- 直接查看旧皮肤包时，导入预览也会按模板显示有效最低版本 `1.2.0`。
- Setup 仍面向普通用户；皮肤设计器仍是可见但默认不勾选的可选组件。
- 默认保留 HUD 设置、已安装皮肤、设计器草稿及预览窗口状态。

发布资产：

- `CodexQuotaHud-Setup-v1.2.2.exe`
- `CodexQuotaHud-v1.2.2-win-x64.zip`
- `SHA256SUMS.txt`

Setup 为当前用户安装，不需要管理员权限。当前安装包未签名，Windows SmartScreen
可能显示未知发布者；请使用 `SHA256SUMS.txt` 核对下载文件。

## English

`v1.2.2` corrects skin-package metadata without changing the `.cqskin` schema
or installer structure.

- Skin import now labels package metadata simply as `Author`. The application
  has no author-identity verification system, so it no longer marks every
  author with a misleading unverified state.
- The built-in `free-decoration-ring` template now automatically declares its
  true minimum compatible HUD version as `1.2.0`, instead of relying on an
  incorrect `1.1.1` value supplied by UI code or package authors.
- Older drafts, installed skins, and packages imported for editing are
  normalized to the effective template minimum inside the Designer. Their next
  save, apply, or export writes the corrected value.
- Import preview also displays the effective `1.2.0` minimum for older packages.
- Setup remains ordinary-user oriented. Skin Designer remains a visible,
  optional component that is unchecked by default.
- HUD settings, installed skins, Designer drafts, and preview state remain
  preserved by default.

Release assets:

- `CodexQuotaHud-Setup-v1.2.2.exe`
- `CodexQuotaHud-v1.2.2-win-x64.zip`
- `SHA256SUMS.txt`

Setup installs for the current user and does not require administrator rights.
The binaries are currently unsigned, so Windows SmartScreen may warn about an
unknown publisher. Verify downloads with `SHA256SUMS.txt` before running them.
