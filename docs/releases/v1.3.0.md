`v1.3.0` 补齐皮肤作者的文字构图与预览验收工具：

- 新增“文字整体上下偏移”（`-32..32 DIP`）和“数字/时间间距”
  （`-16..32 DIP`）两个持久化参数。旧 v1.2.x 包缺字段时按 `0/0` 读取，
  原视觉不变；新输出仍使用 schema `1`，但最低 HUD 自动声明为 `1.3.0`。

- 明确显示 `free-decoration-ring` 模板预览的 Dual 外圈为 5 小时、内圈为每周，
  并同步说明 5h、Week、None；五款内置皮肤保留既有圈层几何。
- Windows 原生导出选择器会从 `Documents\Codex Quota HUD Skins` 开始，
  文件名栏只放叶子 `.cqskin` 名称。
- 应用与导出结果显示准确的皮肤名、版本、ID、最终目录和真实激活状态；
  “已安装但未确认切换”不会写成实时切换成功。
