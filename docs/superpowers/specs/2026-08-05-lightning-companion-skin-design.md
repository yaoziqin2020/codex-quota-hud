# 雷光伙伴皮肤设计规格

日期：2026-08-05

状态：视觉方案已获用户批准，等待书面规格复核

目标 HUD：Codex Quota HUD v1.2.3 及更高版本

## 1. 目标

使用现有 Codex Quota HUD 皮肤设计器制作一款可公开分享的原创皮肤
`雷光伙伴`。成品以柔光玫瑰的精致、柔和与动画完整度为质量参照，但不复用其
玫瑰素材、角色或主色；新皮肤采用电光黄、炭黑与冰蓝，并以原创角色
`圆耳电团兽`作为中心视觉。

本工作交付设计器草稿、已应用的本机 HUD 皮肤和可分享 `.cqskin` 包。本工作不修改
HUD、Skin Designer、安装器或 `.cqskin` schema，也不发布新的 HUD 版本。

## 2. 原创与版权边界

- 角色是原创圆耳电团兽，不使用皮卡丘、宝可梦或其他现有动漫/游戏角色的名称、
  轮廓、面部特征、配件或品牌标识。
- 素材由内置图像生成能力为本项目单独生成，不使用网络下载的角色图或受限素材。
- 图片不得包含文字、水印、签名、Logo 或可识别商标。
- 成品定位为可由作者公开分享的数据皮肤包，而非只适用于本机的私有草稿。

## 3. 视觉方向

### 3.1 角色与材质

- 角色：原创圆耳电团兽。
- 材质：A1a 柔光 3D；圆润、轻微毛绒纹理、暖色体积光和柔和边缘光。
- 气质：可爱但不幼稚，像一枚放在桌面的精致电子伙伴。
- 主色：电光黄；辅色：冰蓝；背景：炭黑偏蓝。
- 最终构图采用用户批准的 B 版留白构图，并在不侵占文字安全区的前提下将圆脸
  相对该参考轻微放大约 3%。

### 3.2 动态文字与脸部构图

动态额度文字不烘焙进图片，继续由 HUD 实时绘制。现有模板固定使用
`numberAboveLabel`：数字相对中心上移 18 DIP，标签相对中心下移 25 DIP。

中心图必须围绕该固定布局设计：

- 角色头部保持视觉居中，不为迁就文字整体漂到上方。
- 两只耳朵向上并向外展开，内侧必须为最长三位额度文本（例如 `100%`）保留
  清晰安全区。
- 百分比位于耳根下方、两只外扩小眼睛之间，读起来像额头上的发光能量标记；
  最长 `100%` 不能碰到耳根或任何一只虹膜。
- 两只眼睛分布在数字两侧，嘴位于数字下方、周期标签上方。
- `5 小时` 或 `每周` 位于嘴巴正下方，不覆盖嘴或下巴。
- 中心图最终使用 `offsetY = -4`、界面目标 `scale = 1.03`。`-4 DIP` 是实际预览
  验证后的抗碰撞偏移，角色最终仍须看起来居中。
- 字体参数为数字 18、标签 12、SemiBold、暖白色；不增加深色徽章或遮挡角色的
  独立文字底板。

## 4. 三张素材

生成阶段在仓库忽略目录
`artifacts/skins/lightning-companion/source-assets/` 保存工作素材，便于裁切和复核；
不把临时图或生成中间文件提交到 Git。

### 4.1 背景图

- 1024×1024 正方形，PNG 或高质量 JPEG。
- 炭黑到深海军蓝的柔和电气空间。
- 有克制的黄色与冰蓝环境光、稀疏微小火花和暗部层次。
- 不放角色，不画额度圈，不含文字。
- 在 132×132 HUD 尺寸下不得出现脏噪点或抢夺中心角色的高亮区域。

### 4.2 中心图

- 1024×1024 正方形，使用与背景相容的深色不透明底，避免复杂毛发透明抠图。
- 正面柔光 3D 圆耳电团兽头像；耳朵向外、额头留白、眼睛稍低、嘴略靠上。
- 以 64×64 圆形裁切为最终判定标准，必须同时适配 `68%` 和 `100%`。
- 图像本身不绘制数字、周期、进度圈或额外 UI。
- 整个中心图参与呼吸缩放；微小偏移或裁切焦点不得破坏呼吸动画。

### 4.3 装饰图

- 1024×1024 透明 PNG。
- 使用 Alpha 透明通道形成完整效果层：大范围、低透明度的黄色柔光晕作为环境光，
  其上分布更亮的柔光闪电、星芒、电弧碎片和少量微光火花；元素之间保持透明，
  不额外画一整圈连续或实心的装饰环。
- 先在纯色键控背景上生成，再使用项目指定的 chroma-key 移除脚本得到透明图，
  并检查边缘无绿色/品红色污染。
- 装饰图承担旋转和轻微浮动，不承载任何额度数据。
- 黄色柔光晕可从黄色 5 小时数据圈附近向外羽化，但必须保持半透明、无硬边且不
  形成不透明底色；更亮的闪电、星芒和火花主要分布在黄色圈之外，不碰动态文字，
  也不伪装成第三条额度进度圈。
- HUD 自身的 `glowIntensity` 继续负责数据圈脉冲；透明素材中的黄色光晕只负责
  持续环境光。两者叠加时不得过曝成整块实心黄雾。
- 冰蓝每周数据圈必须以呼吸放大到峰值后的圆脸为边界，保持在脸外并保留约
  2 DIP 的径向安全间隙；静止时可出现少量自然暗部间隔。不得让呼吸后的脸覆盖
  或穿过冰蓝数据圈。

| 基础底色 | `#FF10141B` |
| 基础底色不透明度 | `0.82` |
| 光晕颜色 | `#FFFFE35A` |
| 静态光晕强度 | `0.62` |

| 环粗 | `7` DIP |

| 起始角度 | `270°` |
| 数字字号 | `18` DIP |
| 标签字号 | `12` DIP |
| 字重 | `semiBold` |

三张图片从以下变换值起调：

| 图层 | Offset X / Y | Scale | Rotation | Opacity | Crop Focus X / Y |
| --- | --- | ---: | ---: | ---: | --- |
| 背景 | `0 / 0` | `1.00` | `0°` | `1.00` | `0.5 / 0.5` |
| 中心角色 | `0 / -4` | `1.03` | `0°` | `1.00` | `0.5 / 0.5` |
| 透明装饰 | `0 / 0` | `1.00` | `0°` | `1.00` | `0.5 / 0.5` |

只有中心角色的 Offset Y 可以在实际预览中按第 3.2 节进行 ±4 DIP 微调；其余变换
若需偏离本表，必须有明确的裁切或视觉证据。

双额度时，现有模板的主额度是 5 小时、主环直径为 102 DIP；副额度是每周，副环
直径按 `102 - 2 × (7 + 2)` 得到 84 DIP。副环 7 DIP 的描边留下约 77 DIP 的
内侧开口。中心图基础直径为 64 DIP、基础缩放为 1.03；呼吸强度 0.88 的峰值
倍率为 `1 + 0.12 × 0.88 = 1.1056`，所以峰值脸直径约为
`64 × 1.03 × 1.1056 = 72.9` DIP。内圈在峰值脸外仍保留约 2 DIP 的径向安全
间隙。最终视觉层级从外到内为：透明黄色柔光晕及电光装饰、黄色 5 小时数据圈、
冰蓝每周数据圈、呼吸中的中心角色。

若仅存在一个额度窗口，现有 HUD 会把该窗口作为主额度并使用黄色主环；皮肤包不
尝试改变此运行时规则。低额度告警时数据环颜色仍由现有 HUD 告警调色板接管。

## 6. 动画参数

所有现有动画通道均启用：

| 动画 | 参数 | 视觉职责 |
| --- | ---: | --- |
| 装饰旋转 | `0.78` | 透明黄晕、电光碎片与星芒持续绕行 |
| 中心呼吸 | `0.88` | 圆耳电团兽柔和缩放，保持角色有生命感 |
| 光晕脉冲 | `0.92` | 黄色与冰蓝边缘能量明暗变化 |
| 装饰浮动 | `0.18` | 火花与电弧轻微漂移，不产生明显抖动 |
| 刷新速度 | `3.5×` | 刷新时动画进入充能加速状态 |
| 加速延续 | `3.0 秒` | 刷新结束后维持加速效果再平滑回落 |

`3.0 秒` 是 v1.2.3 现有 schema 的允许上限；不得在皮肤文件中人工写入 4 秒或其他
越界值。

### 6.1 Designer 数值表示精度

v1.2.3 Designer 的连续参数使用无数值输入框的 WPF 滑杆，鼠标轨道位置会序列化为
最接近的浮点值。因此本规格中的连续数值是界面目标值，不要求绕过 Designer 直接
修改 JSON。验收容差为：中心缩放 `±0.001`；基础不透明度、静态光晕和四项动画强度
各 `±0.003`；环直径 `±0.1` DIP；起始角度 `±1°`。颜色、离散环参数、文字字号与
排布、刷新速度 `3.5×`、加速延续 `3.0 秒` 仍须精确保存。预览与安全间隙计算使用
草稿中实际保存的连续值。

## 8. 制作流程

1. 使用内置图像生成能力分别生成背景、中心角色和键控背景装饰素材。
2. 将生成结果复制到工作区忽略目录，检查尺寸、色彩、边缘和版权边界。
3. 对装饰素材执行 chroma-key 去背并人工检查透明边缘。
4. 打开已安装的 Codex Quota HUD 皮肤设计器，新建独立草稿，避免覆盖用户现有草稿。
5. 导入三张素材并按本规格录入颜色、环形、文字和动画参数。
6. 使用 Designer 的 Dual / Single 合成预览微调中心图裁切、缩放与不超过 ±4 DIP 的
   纵向偏移，优先保证 `100%` 不碰耳朵、周期文字不碰嘴。
7. 保存草稿，应用到 HUD，再导出包到：
   `C:\Users\yaozi\Documents\Codex Quota HUD Skins\雷光伙伴.cqskin`。
8. 独立读取导出包的 manifest、theme 和资产清单，确认值与本规格一致。

## 9. 验证与验收

### 9.1 设计器内

- Dual：5 小时 68%、每周 34%。
- Dual 极限：主额度 100%，确认数字不碰两侧耳朵。
- Single：仅 5 小时与仅每周各检查一次。
- 动画开、动画关、刷新中状态各检查一次。
- 检查旋转、呼吸、光晕、浮动四个常驻通道均肉眼可见且互不替代。
- 在呼吸动画峰值逐帧观察，圆脸不得覆盖、穿过或压住冰蓝内圈。
- 刷新加速为 3.5×，刷新完成后加速状态持续约 3 秒。
- 透明装饰不得出现矩形底、键控残色、硬边光晕或根级裁切；黄晕与 HUD 脉冲叠加
  时不得过曝。

### 9.2 正式 HUD

- “应用到 HUD”后皮肤立即出现在皮肤列表并立即切换，无需重启。
- 详情开/关、贴边、展开、刷新中和低额度颜色状态下没有裁切或遮挡。
- 关闭并重新启动 HUD 后仍能加载并切换该皮肤。
- 动画全局关闭时所有自定义动画停止；重新开启后恢复。
- 双圈与单圈模式的主数字、标签和进度数据与正式额度状态一致。

### 9.3 导出包

- `.cqskin` 可由正式 HUD 的导入流程识别。
- 导入预览显示名称、作者、版本、最低 HUD 版本、模板和三张资产正确。
- 在不依赖 Designer 的 HUD 环境中也能安装和使用。
- 导出包仅包含允许的数据文件与图片，不含代码、远程 URL 或额外可执行内容。

## 10. 非目标

- 不增加文字行距、独立文字偏移或主副数据圈互换能力。
- 不改变 v1.2.3 的 0–3 秒加速延续范围。
- 不修改柔光玫瑰或其他已安装皮肤。
- 不制作安装器、不更新 Setup/ZIP、不创建 GitHub Release。
- 不把此皮肤加入 HUD 的五款内置皮肤；它作为可导入的自定义 `.cqskin` 交付。
