## 简体中文

`v1.2.3` 修正刷新动画的可见时序，并统一皮肤设计器自有对话框的深色视觉。

- 五套内置皮肤保留原有刷新速度特征；刷新完成后继续保持 1.5 秒加速状态。
- 自定义皮肤可设置 `0x..4x` 的绝对刷新倍速与 `0..3` 秒的加速延续时间。
- 旧皮肤包没有新字段时自动按 `2x` 与 `1.5` 秒运行，无需迁移或重新导出。
- 重复刷新会取消旧计时并启动新的完整延续；隐藏 HUD、关闭动画、切换皮肤、
  解绑或退出会立即取消，不会叠加计时器或倍速。
- 皮肤设计器新增“刷新速度”和“加速延续”控件；新保存、应用或导出的包会写入
  两个规范字段并声明最低 HUD `1.2.3`。
- 皮肤设计器自有确认、冲突、未保存、成功、警告和错误消息改为可访问的深色主题
  对话框；Windows 原生打开/保存文件选择器保持不变。
- Setup 仍面向普通用户，皮肤设计器仍是可见但默认不勾选的可选组件；ZIP 仍仅含
  正式 HUD 后备包，不含设计器。

## English

`v1.2.3` makes refresh animation timing visible and gives Skin Designer-owned
dialogs a consistent dark theme.

- All five built-in skins keep their existing refresh-speed character and hold
  the accelerated state for 1.5 seconds after refresh completion.
- Custom skins can choose an absolute `0x..4x` refresh multiplier and a `0..3`
  second completion hold.
- Older packages without either property default to `2x` and `1.5` seconds;
  they require no migration or re-export.
- Re-refresh cancels the old delay and starts one new full hold. Hiding the HUD,
  disabling animation, switching skins, detaching, or disposing cancels it
  immediately without stacking multipliers or timers.
- Skin Designer exposes Refresh speed and Completion hold controls. Newly saved,
  applied, or exported packages write both canonical properties and declare HUD
  `1.2.3` as their minimum.
- Designer-owned confirmation, collision, unsaved, success, warning, and error
  messages use accessible dark-themed dialogs. Native Windows open/save pickers
  remain unchanged.
- Setup remains ordinary-user oriented, with Skin Designer visible but unchecked
  by default. The fallback ZIP remains normal-HUD-only.

Release asset names:

- `CodexQuotaHud-Setup-v1.2.3.exe`
- `CodexQuotaHud-v1.2.3-win-x64.zip`
- `SHA256SUMS.txt`

The exact release is installed locally, passed user practical acceptance, and
is publicly available from the link above. Verify `SHA256SUMS.txt` before
running Setup. The binaries remain unsigned, so Windows SmartScreen may warn
about an unknown publisher.
