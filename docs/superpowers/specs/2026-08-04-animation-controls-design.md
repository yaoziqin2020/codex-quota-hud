# 皮肤编辑器动画控件简化设计

## 目标

让普通创作者不用理解渲染图层和 0–1 强度含义，也能一键得到肉眼可见、不过分晃眼的动画；熟悉参数的创作者仍可继续细调。

## 已确认方案

采用“预设优先，高级细调可选”的交互：

- 动画区顶部提供三个直接操作的预设按钮：`静止`、`柔和`、`明显`。
- `高级细调`默认收起，展开后保留四个强度滑块。
- 四个参数使用面向效果的中文名称：`装饰旋转`、`中心呼吸`、`额度环光晕`、`装饰浮动`。
- 草稿没有装饰图时，`装饰旋转`和`装饰浮动`滑块禁用，并显示“需要先添加透明装饰图”的说明；预设同时把这两个参数写为 0，避免保存无效配置。
- 添加装饰图后，两个装饰参数立即可用；移除装饰图后，编辑器不偷偷改写已有草稿参数，但预览和提示明确指出它们当前不可见。再次点击预设时按当前素材状态生成有效参数。

## 预设参数

| 预设 | 有装饰图 | 无装饰图 |
| --- | --- | --- |
| 静止 | 旋转 0、呼吸 0、光晕 0、浮动 0 | 同左 |
| 柔和 | 旋转 0.45、呼吸 0.45、光晕 0.55、浮动 0.15 | 旋转 0、呼吸 0.55、光晕 0.65、浮动 0 |
| 明显 | 旋转 0.8、呼吸 0.9、光晕 0.9、浮动 0.25 | 旋转 0、呼吸 0.9、光晕 0.9、浮动 0 |

`柔和`是新草稿的默认动画预设。已有草稿继续按原参数加载，不做迁移或静默改写。

## 组件边界与数据流

- `AnimationPreset`只描述预设名称和四个最终强度值，不包含 WPF 控件逻辑。
- `AnimationEditorViewModel`负责根据当前是否存在装饰素材解析预设，并通过一次草稿变更提交四个参数，保证撤销/重做把一次预设操作视为一个步骤。
- `MainWindow`只负责按钮、折叠区、标签和启用状态绑定；滑块仍走现有的单参数编辑路径。
- 图片添加或移除后，图片工作流发出既有状态更新，动画编辑区随之刷新装饰参数可用性。
- 每次预设或细调成功提交后，继续走现有实时预览构建链，不写正式 HUD 设置。

## 错误与边界处理

- 预设产生的参数必须经过现有 `SkinContractValidator`；验证失败时不部分写入草稿。
- 无装饰图时直接细调装饰参数不可用，不依赖事后警告。
- 用户手工细调后不强行标成某个预设；界面显示为“自定义”，避免误导。
- Windows 全局关闭动画时继续遵循现有静态终态策略，预设不绕过系统设置。

## 测试与验收

- 单元测试覆盖三个预设在有/无装饰图时的精确参数。
- 验证一次预设点击只产生一次草稿修订，并支持一次撤销恢复全部四个参数。
- WPF 测试覆盖默认收起、三个按钮、展开高级细调、无装饰图时两项禁用及提示。
- 回归验证添加/移除装饰图后控件状态即时刷新，预览仍实时更新。
- 人工验收用“柔光玫瑰”草稿检查：`柔和`可见但不抢眼，`明显`能在两秒内看出装饰位置变化。

## 不在本次范围

- 不增加动画时间轴、关键帧、速度曲线编辑器或更多模板专属参数。
- 不修改已安装皮肤包格式和 schema。
- 不改变正式 HUD 的全局动画开关语义。
