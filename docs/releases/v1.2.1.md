# Codex Quota HUD v1.2.1

## 简体中文

`v1.2.1` 是 `v1.2.0` 的动画表现修正版，不改变皮肤包格式或安装器结构。

- 修正额度进度环光晕：整圈光晕即使调到最高，也会明显暗于真实进度弧，
  不再产生“额度像是满的”错觉。
- 修正外层装饰浮动：0–1 强度现在对应清晰有效的位移和速度；0 仍表示关闭。
- 现有 `.cqskin` 皮肤包无需重新制作，升级 HUD 后会自动使用新动画公式。
- Setup 仍默认安装正式 HUD；“皮肤设计器”仍是可见但默认不勾选的可选组件。
- 默认保留 HUD 设置、已安装皮肤、设计器草稿及预览窗口状态。

## English

`v1.2.1` is an animation-behavior correction for `v1.2.0`. It does not change
the skin-package schema or installer structure.

- The full-ring quota glow remains visibly dimmer than the real progress arc,
  including at maximum intensity, so it no longer resembles a full quota.
- Decoration floating now maps the existing 0–1 intensity to practical,
  responsive travel and timing; zero still disables the effect.
- Existing `.cqskin` packages need no rebuild and automatically use the new
  motion profile after the HUD is upgraded.
- Setup still installs the normal HUD by default. Skin Designer remains a
  visible, optional component that is unchecked by default.
- HUD settings, installed skins, Designer drafts, and preview state remain
  preserved by default.
