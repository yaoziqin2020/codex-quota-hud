# Codex Quota HUD v1.1.0 release candidate

## English

`v1.1.0` makes the current-user Inno Setup installer the primary Windows
installation path. It supports English and Simplified Chinese, requires no
administrator elevation, and upgrades `v1.0.0` in place while preserving HUD
settings and Developer Preview window state by default.

The installer selects startup and the normal desktop shortcut by default. The
release Setup contains no Developer Preview shortcut option. ZIP users can run
`CodexQuotaHud.App.exe --preview` explicitly for development testing. Normal
uninstall preserves settings; the user must explicitly opt in to purge the
exact settings directory.

The Setup executable is unsigned, so Windows SmartScreen can show an
unknown-publisher warning. Verify the downloaded SHA-256 against
`SHA256SUMS.txt` before running it. The ZIP and bundled PowerShell installer
remain a fallback only. GitHub Packages is not used.

Release-candidate assets (names only; this document does not state that they
are uploaded):

- `CodexQuotaHud-Setup-v1.1.0.exe`
- `CodexQuotaHud-v1.1.0-win-x64.zip`
- `SHA256SUMS.txt`

Automated evidence as of this candidate: Core `55/55`, App/UI `331/331`, total
`386/386`; Release build `0` warnings and `0` errors; all four isolated smoke
scenarios passed. Real corrected-Setup overwrite and default shortcut behavior
were observed; both uninstall modes remain pending.

## 简体中文

`v1.1.0` 将当前用户 Inno Setup 安装器作为 Windows 的主要安装方式。安装器支持英文和
简体中文，不需要管理员权限；可原地从 `v1.0.0` 升级，默认保留 HUD 设置和开发预览窗口状态。

安装器默认勾选开机启动和普通桌面快捷方式，正式 Setup 不提供“开发预览”快捷方式选项。
ZIP 用户需要开发测试时可明确运行 `CodexQuotaHud.App.exe --preview`。普通卸载保留设置；
只有用户明确选择清除时，才会删除准确的设置目录。

Setup 未签名，Windows SmartScreen 可能显示未知发布者提示。运行前应使用 `SHA256SUMS.txt`
核对 SHA-256。ZIP 和其中的 PowerShell 安装脚本仅作为后备路径；不使用 GitHub Packages。

上述资产名称仅表示本候选版本的计划发布资产，不表示已经上传。自动化证据为 Core `55/55`、
App/UI `331/331`、总计 `386/386`，Release 构建 `0` 警告、`0` 错误，四个隔离 smoke 场景均通过。
修正版真实覆盖安装和默认快捷方式已观察；两种卸载模式仍待验收。
